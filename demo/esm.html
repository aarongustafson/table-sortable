table-sortable via esm.sh

This page loads the component class from esm.sh and registers it manually. See the README for the API.

Class-only import and manual registration

The class import does not register an element. The captioned table remains readable if JavaScript or the CDN fails; sort buttons appear only after enhancement. At narrow widths, focus the table region and use arrow keys to scroll. 

<script type="module">
  import { TableSortableElement } from 'https://esm.sh/@aarongustafson/table-sortable@2.1.4/table-sortable.js?bundle&target=es2022';
  if (!customElements.get('table-sortable')) {
    customElements.define('table-sortable', TableSortableElement);
  }
</script>

<table-sortable tabindex="0" role="region" aria-label="People table">
  <table>
    <caption>People and cities</caption>
    <!-- Plain headers and data rows -->
  </table>
</table-sortable>
