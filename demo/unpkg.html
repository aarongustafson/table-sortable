table-sortable via unpkg

This page loads the guarded definition helper from unpkg. Importing it registers the element when supported; the explicit helper call is safe to repeat. See the README for the API.

Automatic registration

The captioned table remains readable if JavaScript or the CDN fails; sort buttons appear only after enhancement. At narrow widths, focus the table region and use arrow keys to scroll. 

<script type="module">
  import { defineTableSortable } from 'https://unpkg.com/@aarongustafson/table-sortable@latest/define.js?module';
  defineTableSortable();
</script>

<table-sortable tabindex="0" role="region" aria-label="People table">
  <table>
    <caption>People and cities</caption>
    <!-- Plain headers and data rows -->
  </table>
</table-sortable>
